# Playwright Automation Testing

## Project Purpose
This project was created to practice and develop my test automation skills using Playwright and TypeScript.

## Tools Used
- Visual Studio Code
- Playwright
- TypeScript
- Node.js
- Git and GitHub

## How to Run Tests

1. Clone this repository.
2. Install dependencies:

npm install

3. Run Playwright tests:

npx playwright test

4. View the test report:

npx playwright show-report

## Test Scenarios Covered

- Login functionality
  - Valid login
  - Invalid login
  - Locked user validation

- Product Management
  - Add product to cart
  - Cart validation

- Checkout process

- Logout functionality

## Framework Structure

- tests/ - Contains automated test cases.
- pages/ - Contains Page Object Model classes.
- fixtures/ - Contains reusable test fixtures.
- test-data/ - Contains JSON test data for data-driven testing.
